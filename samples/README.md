# Sample course materials

These PDFs are synthetic fixtures generated by `npm run samples` for local review and automated tests. They are not real lecture slides.

| File | Purpose |
|---|---|
| `neural-networks/Lecture 1 - Perceptron and Backpropagation.pdf` | Three-page text PDF with numbered headings on pages 1–3. |
| `neural-networks/Lecture 2 - Convolutional Neural Networks.pdf` | Second lecture for the same course, demonstrating a multi-lecture outline. |
| `data-science/Lecture 1 - Data Cleaning and Exploratory Analysis.pdf` | A second course, demonstrating course switching. |
| `scanned-image-only.pdf` | Valid PDF with no text layer; used to verify the OCR-not-implemented warning. |
| `not-a-pdf.txt` | Used to verify that non-PDF uploads are rejected. |

The PDFs contain a repeated header/footer and page numbers. CourseAtlas removes repeated page furniture while preserving the stored page number, so citations point at the original page rather than the visible footer text.
